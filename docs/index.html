Quick Start

Get up and running with SuryaPy in just a few lines of code. This example loads a solar image, detects sunspots, and measures their areas.

from astrolab import imaging as im
from scipy import ndimage as scp
import suryapy

# Load and filter a solar image
raw_image = im.load_image("DSC_1036.JPG")
filtered = scp.gaussian_filter(raw_image, sigma=0.5)

# Mask the solar disk
cropped = suryapy.mask_sun(filtered, sun_threshold=50)

# Apply Bradley-Roth thresholding
br_mask = suryapy.b_roth(cropped, threshold=9, Nx=100)

# Find sunspots (connected components)
labeled, n, _, _, bbox = suryapy.find_components(
    br_mask, cropped, min_size=1000
)

print(f"Found {n} sunspots!")

What's happening here?

  1. Load and filter: Read a solar image and apply Gaussian filtering to reduce noise
  2. Mask the solar disk: Crop to just the sun and apply a mask to avoid analyzing the background
  3. Threshold: Use Bradley-Roth adaptive thresholding to identify dark regions (sunspots)
  4. Find components: Use connected component analysis to identify individual sunspots
💡 Tip: Start with default parameters (threshold=9, Nx=100) and adjust based on your image quality.

Advanced Guide

Complete workflow showing how to measure multiple sunspots with physical corrections applied

# Full analysis pipeline
corrected = suryapy.limb_darkening_correction(cropped)
br = suryapy.b_roth(corrected, threshold=9, Nx=100)
labeled, n, _, sizes, bbox = suryapy.find_components(br, cropped)

# Measure each sunspot
for i in range(1, n+1):
    info = suryapy.inspect_component(i, labeled, n, bbox, br, cropped)
    area_px = info['area_pixels']
    
    # Correct for foreshortening
    y, z = info['centroid_y'], info['centroid_z']
    area_corr = suryapy.foreshortening_correction(area_px, y, z)
    
    # Convert to millionths of solar hemisphere
    area_km2 = suryapy.pixels_to_km2(area_corr, km_per_pixel=458.58)
    area_mh = suryapy.km2_to_millionths(area_km2)
    
    print(f"Spot {i}: {area_mh:.2f} MH")

Parameter Tuning

Parameter Default Effect
threshold 9 Sensitivity (5-20 typical). Higher = more aggressive
Nx 100 Window divisor. Smaller = larger window
min_size 1000 Minimum component area (pixels) to keep
💡 Tip: Always apply limb darkening correction before thresholding. The solar disk edge appears artificially dark and can confuse the algorithm.

Calibration Example

For your setup (DSLR + 8" CELESTRON), use:

km_per_pixel = 458.58  # DSLR + 8" telescope calibration
pixels_to_mh_factor = (km_per_pixel / 696000) ** 2 * 1e6
